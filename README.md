# BC Data Catalogue (catalogue-data-gov-bc-ca)

BC Data Catalogue is a provincial government open-data portal for Canada running **CKAN**, exposing a standardized catalog API over ~3,346 datasets.

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/catalogue-data-gov-bc-ca/refs/heads/main/apis.yml)

**Run:** [Capabilities Using Naftiko](https://github.com/naftiko/fleet?utm_source=api-evangelist&utm_medium=readme&utm_campaign=catalogue-data-gov-bc-ca-api-evangelist&utm_content=repo)

## Type
- **kind:** government  ·  **software:** CKAN  ·  **version:** 2.9.5

## API
- **BC Data Catalogue CKAN Action API** — base `https://catalogue.data.gov.bc.ca/api/3/action`. [Docs](https://docs.ckan.org/en/latest/api/) · [Portal](https://catalogue.data.gov.bc.ca)
- Live endpoint verified: `https://catalogue.data.gov.bc.ca/api/3/action/status_show` · ~3,346 datasets
